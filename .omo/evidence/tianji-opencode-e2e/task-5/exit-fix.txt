=== 任务 5:修复 e2e/chat.ts main() 的 process.exit 导致 finally/cleanup 不执行、临时目录泄漏 ===
时间: 2026-08-09

=== 1. 代码修改(e2e/chat.ts,仅 main() 退出路径)===
修复前:
  main() 内:      process.exit(result.ok ? 0 : 1);
  import.meta.main 的 catch: process.exit(1);
  → process.exit 同步终止进程,跳过 finally 中的 scaffold.cleanup(),临时目录泄漏
修复后(镜像 e2e/command.ts main() 330-356 的 exitCode + finally 模式):
  main() 内:      if (!result.ok) process.exitCode = 1;
  catch 中:       process.exitCode = 1;
  → main() 正常返回,finally 的 await scaffold.cleanup() 必然执行
  runRealChat 行为零改动
