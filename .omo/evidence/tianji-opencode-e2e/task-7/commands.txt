```sh

```

```sh

```
→ exit 1;打印 `[keep] 运行失败,保留临时目录供排查:<dir>`;目录保留;验证后 rm -rf 清理

### 4. happy 路径(全量真实,消耗少量 API)

bun run e2e/run.ts
