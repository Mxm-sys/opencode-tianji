# Task 4 · Header-Encoding Fix (x-opencode-directory with CJK path)

Date: 2026-08-09
Scope: `e2e/tools.ts` only

## Bug

`fetchToolIds()` sent `x-opencode-directory` with the raw directory path.
opencode server (v1.18.15, packages/server/src/location.ts) decodes the header
value with `decode()`, so a raw CJK path fails:

```
请求 /experimental/tool/ids 失败:Header 'x-opencode-directory' has invalid value: '/home/mm/桌面/opencode/项目/天机测试场'
```

## Fix

`e2e/tools.ts:246` — `fetchToolIds()`:

```diff
-      headers: { "x-opencode-directory": dir },
+      headers: { "x-opencode-directory": encodeURIComponent(dir) },
```

Chinese doc-comment added above the function documenting the contract:
server decodes (decode()), so client must encode (encodeURIComponent).

Grep audit for `x-opencode-directory` in e2e/: only `fetchToolIds()` sends the
header (tools.ts:250→encoded). run.ts / chat.ts / command.ts use the `--dir`
flag, untouched.
